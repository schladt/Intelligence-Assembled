# Roadmap

### *From first principles to modern AI.*

This document describes the full curriculum for **Intelligence, Assembled**. The stack is ordered so that each section builds on the ones before it. The exact structure will evolve as modules are written, but the trajectory is intentional: start with the mathematics, build toward machine learning, and arrive at modern AI with a real understanding of why things work.

Each module aims to move through several layers:

**Intuition → Mathematics → Derivation → Implementation → Experimentation → Exercises**

Not every topic requires all six, but that is the general direction.
